# Building Code AI Assistant

A simple, frontend-only AI chatbot for the **Building Code of Australia (BCA) 2022 Volumes 1 & 2**. This application provides conversational explanations and code search functionality to help users understand building regulations.

## ✨ Features

### 🤖 AI Chatbot
- **Conversational Interface**: Natural language interaction for building code queries
- **Smart Responses**: Context-aware answers about BCA 2022 requirements
- **Expert Knowledge**: Covers fire safety, accessibility, structural, energy efficiency, and more

### 🔍 Code Search
- **Keyword Search**: Find specific clauses, requirements, or topics
- **Highlighted Results**: Visual emphasis on matching search terms
- **Instant Results**: Fast client-side search through building code data

### 💻 Clean Interface
- **Modern Design**: Professional interface using Inter font
- **Responsive Layout**: Works on desktop, tablet, and mobile
- **Intuitive Navigation**: Easy-to-use chat and search functionality

## 🚀 Quick Start

**Just open `index.html` in your web browser!**

### Option 1: Direct File Opening
1. Download the files: `index.html`, `style.css`, and `script.js`
2. Double-click `index.html` to open in your browser

### Option 2: Local Server (Recommended)
```bash
# If you have Python installed
python -m http.server 8000

# Then open http://localhost:8000 in your browser
```

### Option 3: Live Server (VS Code)
1. Install the "Live Server" extension in VS Code
2. Right-click `index.html` and select "Open with Live Server"

## 📚 Coverage Areas

- **Fire Safety**: Detection systems, egress requirements, fire resistance
- **Accessibility**: Design standards, AS 1428 compliance, access requirements
- **Structural Provisions**: Load requirements, foundation design, material standards
- **Energy Efficiency**: Thermal performance, insulation, star ratings
- **Residential Buildings**: Class 1 & 2 specific requirements
- **Commercial Buildings**: Class 3-9 provisions
- **Health & Amenity**: Ventilation, lighting, space requirements
